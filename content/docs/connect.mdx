# Как подключить блог к RazdFeed

RazdFeed собирает посты авторов из GitHub Discussions. Чтобы ваш блог появился в ленте, нужно создать служебный репозиторий `{ваш-логин}/razdfeed` с файлом `.razdfeed.yml`.

## Как это работает

1. Вы пишете посты в виде GitHub Discussions в категории **Announcements** вашего основного репозитория (например, `dealenx/dealenx/discussions/categories/announcements`).
2. Создаёте служебный репозиторий `dealenx/razdfeed` и добавляете в него файл `.razdfeed.yml`.
3. Бот [fetcher-collector](https://github.com/razdfeed/fetcher-collector) находит этот файл, читает настройки и забирает посты.
4. RazdFeed показывает их в общей ленте и на странице автора.

## Минимальная настройка

Создайте репозиторий `{ваш-логин}/razdfeed` и файл `.razdfeed.yml` в его корне:

```yaml
name: Имя автора
description: Короткое описание блога
language: ru
```

По умолчанию бот возьмёт посты из `{ваш-логин}/{ваш-логин}/discussions/categories/Announcements`.

## Параметры файла

```yaml
name: Имя автора
description: Короткое описание блога
language: ru
category: Announcements
labels:
  - blog
source:
  repo: owner/repo
```

- `name` — имя автора, которое отображается на сайте.
- `description` — описание блога.
- `language` — язык постов (`ru`, `en` и т.д.).
- `category` — категория GitHub Discussions для импорта (по умолчанию `Announcements`).
- `labels` — метки issues/discussions, которые нужно импортировать.
- `source.repo` — репозиторий, где находятся посты. Если не указан, используется `{author}/{author}`.

## Требования

- Служебный репозиторий `{author}/razdfeed` должен быть **публичным**.
- В основном репозитории должны быть включены **Discussions**.
- Для комментариев через giscus нужно установить приложение [giscus](https://github.com/apps/giscus) в основной репозиторий и включить Discussions.

## Подробнее
