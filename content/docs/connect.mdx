# Как подключиться к RazdFeed

RazdFeed собирает посты из двух источников: **Telegram-каналов** и **GitHub Discussions**. Чтобы добавить свой фид, создайте служебный репозиторий `{ваш-логин}/razdfeed` с файлом `.razdfeed.yml`.

## Telegram

1. Создайте публичный репозиторий `{ваш-логин}/razdfeed`, например [dealenx/razdfeed](https://github.com/dealenx/razdfeed).
2. Добавьте файл `.razdfeed.yml`:

```yaml
sources:
  - type: telegram
    url: https://t.me/dealenxdev
```

3. Убедитесь, что Telegram-канал **публичный**.
4. RazdFeed подтянет посты и создаст страницу автора по имени канала, например `/dealenxdev`.

## GitHub Discussions

1. Включите **Discussions** в репозитории, **откуда будут тянуться посты**.
   В нашем примере это [dealenx/dealenx](https://github.com/dealenx/dealenx/discussions/categories/announcements) — именно оттуда RazdFeed забирает обсуждения.
2. Добавьте в `.razdfeed.yml`:

```yaml
sources:
  - type: github
    url: https://github.com/dealenx/dealenx/discussions/categories/announcements
```

3. Пишите посты в категории **Announcements** в репозитории-источнике.
   Пример поста: [dealenx/dealenx/discussions/2](https://github.com/dealenx/dealenx/discussions/2).
4. Для комментариев установите приложение [giscus](https://github.com/apps/giscus).

## Несколько источников

Можно комбинировать:

```yaml
sources:
  - type: github
    url: https://github.com/dealenx/dealenx/discussions/categories/announcements
  - type: telegram
    url: https://t.me/dealenxdev
```

## Требования

- Репозиторий `{author}/razdfeed` должен быть **публичным**.
- Telegram-канал должен быть **публичным**.
- В GitHub-репозитории-источнике должны быть включены **Discussions**.
